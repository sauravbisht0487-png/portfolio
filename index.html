AI-SDLC Platform

Turns requirements into user stories, code, and a GitHub repo.

  • 6-stage workflow (Organization, Project, Requirement, User Story, Code, GitHub) with full CRUD on 4 core entities.
  • 6-layer backend: Routes, Middleware, Controllers, Services, Repositories, Models. JWT auth, protected routes, ownership-based access.
  • Gemini API converts requirements into 3 structured user stories and generates 5 source files via schema-constrained prompts.
  • GitHub API creates repos and pushes the generated code automatically.
  • Dockerized backend, GitHub Actions CI/CD, React + TypeScript frontend with route-level lazy loading.
